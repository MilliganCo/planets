# Falling Sand Simulator

Симулятор falling-sand cellular automaton с материалами: песок, вода, огонь, дым.

## Запуск

Приложение можно запускать из любой директории:

**Из корневой директории проекта:**
```bash
python -m falling_sand.app
```

**Из папки falling_sand:**
```bash
cd falling_sand
python app.py
```

Приложение автоматически настроит пути импорта для работы из любой директории.

## Управление

### Клавиатура

- `1-5` - выбор материала (SAND, WATER, WOOD, FIRE, WALL)
- `E` - ластик (EMPTY)
- `Space` - пауза/пуск
- `.` - один шаг (на паузе)
- `R` - очистить мир
- `F` - загрузить пресет (циклически переключает)
- `[` `]` - скорость симуляции
- `G` - переключение гравитации (Down/Left/Right/Up)
- `W` - переключение ветра (None/Left/Right)
- `T` - режим дождя (вкл/выкл)
- `H` - показать/скрыть подсказки

### Мышь

- ЛКМ - рисовать выбранный материал
- ПКМ - стирать
- Колесо мыши - изменить размер кисти
- Shift + ЛКМ - рисовать линию

## Материалы

1. **SAND** (Песок) - падает вниз, скатывается по диагонали, тонет в воде
2. **WATER** (Вода) - падает и течет, заполняет полости
3. **WOOD** (Дерево) - неподвижный горючий материал
4. **FIRE** (Огонь) - распространяется по дереву, имеет таймер жизни
5. **WALL** (Стена) - неподвижный блок
6. **SMOKE** (Дым) - поднимается вверх, рассеивается со временем

## Пресеты

- **Дюна** - слой песка сверху для осыпания
- **Озеро** - чаша с водой и песком сверху
- **Лес** - деревья с огнем для пожара
- **Дождь** - простая сцена для режима дождя
